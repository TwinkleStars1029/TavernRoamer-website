# 雲端主題改版設計

日期：2026-10-13
狀態：待使用者審閱

## 目標

把網站的整體氛圍從「暗綠旅人手帳」改成**以雲端為主、帶一點酒館元素**的成熟風格，並提供亮色／暗色兩個主題讓使用者切換。

改版只動視覺。版面結構、導覽項目、各頁的段落順序和所有文字內容都維持原樣。

## 設計方向

| | 亮色：霧藍石板 | 暗色：雲上夜燈 |
| --- | --- | --- |
| 天空 | 藍灰到暖石色的漸層 | 深夜藍黑，帶星點 |
| 雲 | 雲頂米白受光、雲底暖褐灰陰影 | 夜空藍雲層 |
| 酒館元素 | 雲底的琥珀暖光、黃銅色細線與小標 | 雲底被燈火映成琥珀色、燈火金按鈕 |
| 內文區 | 溫暖的石白底、白色卡片 | 深夜藍黑底、深藍卡片 |

氛圍來自光線、霧氣、細微顆粒和襯線字體，**不使用**卡通雲、燈籠、啤酒杯之類的圖示。

確認過的視覺稿：`.superpowers/brainstorm/455-1791871783/content/theme-toggle-v3.html`（本機檔案，不進版控）。

### 雲上區塊的變數（sky scope）

現有程式碼中寫死的顏色全部改用變數，涉及：`SiteLayout.astro`、`index.astro`、`install.astro`、`how-to-use.astro`、`data-and-permissions.astro`、`interface.astro`、`OAuthScreenshots.astro`、`PageChapters.astro`。

### 主題的決定與記憶

1. `<head>` 最前面放一段 inline 腳本，在畫面繪製前設定 `<html data-theme="...">`，避免先閃一下錯的主題。
2. 判斷順序：`localStorage` 中的 `tr-theme`（`light` 或 `dark`）→ 系統的 `prefers-color-scheme` → 預設亮色。
3. 使用者按切換鈕後，把選擇寫入 `localStorage`。讀寫 `localStorage` 都包在 `try/catch` 中，失敗時仍能正常切換，只是不記憶。
4. `<meta name="theme-color">` 跟著主題更新（亮色 `#f3f1ec`、暗色 `#10151d`）。

### 切換按鈕

- 位置：導覽列最右邊（「開始安裝」按鈕之後）。手機版放在選單按鈕旁邊，不收進選單。
- 外觀：圓形毛玻璃按鈕。亮色時顯示 ☾，暗色時顯示 ☀。
- 無障礙：`<button type="button">`，`aria-label="切換為暗色主題"`／`"切換為亮色主題"` 隨狀態更新，鍵盤可操作，有明顯的 focus 樣式。
- 切換時顏色以約 0.35 秒漸變；使用者設定 `prefers-reduced-motion: reduce` 時不做漸變。

## 2. 雲朵主視覺

### 共用元件 `CloudSky.astro`

新增 `src/components/CloudSky.astro`，以絕對定位鋪滿所在區塊。兩個主題**共用同一組雲**：形狀、位置、樣態都相同，只透過 CSS 變數換色。

為了讓雲在任何螢幕寬度下都不變形，也不被切掉頂部，元件拆成幾層：

- 天空：CSS 垂直漸層 `--sky-1 → --sky-2 → --sky-3`（`--sky-2` 停在 70%）。
- 星點：右上角的小 SVG，7 個小白點，透明度 `--star-opacity`（亮色 0、暗色 0.6）。
- 飄雲：右上角一朵，獨立的 SVG，漸層 `--puff-1 → --puff-2`。寬度 ≤ 800px 時隱藏，避免壓在文字後面。
- 雲海：貼齊區塊底部的 SVG，固定高度。圖形寬 1600 單位（`viewBox="0 250 1600 200"`、`preserveAspectRatio="xMidYMax slice"`），寬螢幕時依高度縮放、左右置中裁切，所以雲不會被拉扁。漸層 `--bank-1 → --bank-2 → --bank-3 → --bank-4`。
- 底部暖光：雲海 SVG 裡的模糊橢圓，顏色 `--glow`、透明度 `--glow-opacity`。
- 底部淡出：區塊最下方 56px 用 CSS 漸層淡到 `--bg`，讓雲海和內文區無縫接合。
- 雲的質感：`feTurbulence`（`seed=9`）＋`feDisplacementMap` 讓邊緣自然，再加輕微高斯模糊。柔光濾鏡的 filter region 要放大（`x=-50% y=-100% width=200% height=300%`），避免被裁出硬邊。
- 一層細微的顆粒雜訊疊在最上方（`mix-blend-mode: overlay`，約 15% 透明度）。

| 雲朵變數 | 亮色 | 暗色 |
| --- | --- | --- |
| `--sky-1 / -2 / -3` | `#44556a / #56677a / #bdb3a2` | `#0d121a / #172030 / #2a2a33` |
| `--glow` / 透明度 | `#f0b47a` / 0.45 | `#e09a4c` / 0.55 |
| `--puff-1 / -2` | `#f1ece4 / #b5a593` | `#2e3a52 / #6e5a44` |
| `--bank-1 / -2 / -3 / -4` | `#f7f3ec / #cbbdab / #ecc79c / #f3f1ec` | `#3a4760 / #5b5550 / #b8803f / #10151d` |

亮色天空比確認過的視覺稿深一些（原本 `#5a6b7e / #8291a0`），是為了讓天空上的白色說明文字達到 4.5:1。

元件純裝飾，加 `aria-hidden="true"`。每頁只會出現一次元件，所以 SVG 內的 `id` 不會衝突；仍統一加上 `cloud-` 前綴。

### 使用方式

- **首頁**：`<section class="hero sky-scope">` 裡放 `<CloudSky variant="full" />`，包含飄雲和雲海。左側是標題文案，右側保留原本的面板示意圖，改用毛玻璃外框（`--sky-surface` 底、背景模糊、`--line` 細邊），放在雲前面，不再旋轉。示意圖說明文字「介面示意圖｜非實際產品截圖」維持不變。
- **其他 7 頁的標題區**：`<header class="page-hero sky-scope">` 裡放 `<CloudSky variant="compact" />`，同一組雲海，但雲海較矮、不顯示飄雲，讓內文早一點出現。
- 標題區的底部留白要大於雲海最濃的部分，確保文字不會壓在淺色雲上。

### 主視覺上的文字

主視覺和標題區都套用 `.sky-scope`，所以文字、重點字、按鈕、小卡片自動使用上表的 sky 變數。

## 3. 視覺樣式

### 字體

透過 Google Fonts 載入：

- **Noto Serif TC**（700、900）：`h1`、`h2`、品牌名稱。
- **Noto Sans TC**（400、500、700）：內文、`h3`、按鈕、導覽。
- **DM Mono**（400、500）：小標（eyebrow）、步驟編號、標籤、程式碼。

移除 DM Sans。

### 元件

所有既有的共用樣式改用新變數，類別名稱不變，頁面 HTML 不用改。

- **導覽列**：每一頁的導覽列都疊在雲朵標題區上（透明底、套用 sky 變數）。往下捲動超過 8px，或手機版選單打開時，改用 `--topbar-bg` 的半透明實底、背景模糊和 `--line` 下邊線。
- **按鈕**：主要按鈕 `--primary` 底；次要按鈕透明底加 `--line` 邊線；圓角 3px。
- **卡片、步驟、FAQ**：`--surface` 底、`--line` 邊線，圓角加大到 8–10px。
- **小標、步驟編號**：DM Mono，`--accent` 色，小標前面加一條同色短線。
- **提示框**：左側 3px `--accent` 邊線、`--accent-soft` 底；警告版用 `--warning` 邊線。
- **程式碼**：`--code-bg` 底、`--code-text` 字。
- **表格、時間軸、跨裝置流程圖、清單**：同樣改用變數。
- **頁尾**：`--surface` 底、`--line` 上邊線。

## 4. 驗證

- `npm run typecheck`、`npm test`、`npm run build` 都要通過。
- 8 個頁面在亮色與暗色、桌機（1280px）與手機（375px）寬度下逐頁目視檢查：
  - 沒有寫死的舊配色殘留（例如舊的綠色 `#b5c592`）。
  - 主視覺的文字和按鈕清楚可讀。
  - 手機版選單和切換鈕都能正常使用。
- 文字對比度符合 WCAG AA：一般文字 ≥ 4.5:1，大標題 ≥ 3:1。主視覺文案要以它實際壓在的天空顏色計算；亮色天空如果不夠深，就調暗 `--sky-1`／`--sky-2`。
- 切換主題後重新整理頁面，主題會保留，而且載入時不閃爍。
- `localStorage` 被封鎖時（例如無痕模式的某些設定），頁面仍能正常顯示和切換。
